# Счета

Учёт счетов пользователя: дебетовых и кредитных. Счёт — это запись
о принадлежности и состоянии, движение средств живёт в кошельке.

## Что здесь важно

**Кредитный счёт обязан ссылаться на кредит, дебетовый — не может.**
Правило записано и в схеме, и в коде: в схеме — чтобы запись мимо сервиса
не оставила счёт без смысла, в коде — чтобы клиент получил понятную
причину отказа, а не нарушение ограничения из базы.

**Чужой счёт отдаётся как несуществующий.** Ответ «запрещено» подтверждал
бы, что счёт с таким идентификатором есть.

**Баланс не может стать отрицательным** — это ограничение схемы,
а не проверка в обработчике.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/account` | Создать счёт себе; чужому — только с ролью оператора |
| `GET` | `/account/{id}` | Прочитать свой счёт |

Примеры запросов — в [_requests/account.http](../../../_requests/account.http).

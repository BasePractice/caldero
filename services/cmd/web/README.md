# Веб-интерфейс

Единственный интерфейс системы: страница, собранная из того же кода, что
и сервисы. Решение и его цена — в [ADR 0007](../../../docs/adr/0007-web-interface.md).

Сервис делает две вещи: раздаёт статику и отдаёт браузеру адрес API.
Больше он не умеет ничего — API остаётся за шлюзом.

## Что внутри

| Путь | Что это |
|---|---|
| `app/` | Само приложение на Go, собирается под `js/wasm` |
| `static/index.html` | Страница-загрузчик |
| `static/wasm_exec.js` | Загрузчик из дистрибутива Go (BSD-лицензия) |
| `static/app.wasm` | Собранный бандл; в репозитории его нет — это артефакт |

## Сборка

```
make wasm
```

Цель собирает `app.wasm` и копирует `wasm_exec.js` из установленного Go.
`make build` вызывает её сам. В образе то же самое делает `Dockerfile`
перед компиляцией сервиса: статика встраивается через `embed`, и бандл
должен существовать к моменту сборки.

Если бандла нет, сервис поднимается и честно говорит об этом на странице:
ронять раздачу статики из-за несобранного фронтенда незачем.

## Экраны

Вход, профиль, список желаний и лента оповещений. Кошелька нет: он
доступен только по gRPC, а шлюз Community Edition его не проксирует
(EXT-04). WebSocket тоже не используется — по той же причине (EXT-05),
лента читается длинным опросом.

## Что здесь важно

**Модели общие с сервисами.** `wishlist.Item`, `notify.Message`,
`credit.Amount` — те же типы, что отдаёт сервер. Поля не разъедутся молча:
расхождение поймает компилятор.

**Токен только в памяти вкладки.** В `localStorage` его читает любой скрипт
на странице. В `sessionStorage` попадает лишь проверочный код PKCE и живёт
ровно один редирект. Перезагрузка страницы требует повторного входа — это
цена решения, а не недоделка.

**Всё, что приходит из API, экранируется.** Подставлять ответ сервера
в разметку как есть — межсайтовый скриптинг, даже если сервер свой.

**Адрес API не зашит в бандл**, а приходит из `GET /config.json`: один
и тот же файл должен работать и на стенде, и в бою.

# Кредиты

Оформление кредитов и расчёт графика платежей: аннуитетного
и дифференцированного.

## Что здесь важно

**Деньги — целые числа в копейках, ставка — в базисных пунктах.**
Дробные типы для денег не годятся: `0.1 + 0.2` не равно `0.3`, и ошибка
накапливается на каждом платеже. Целые проценты не выражают даже 12,5 %,
поэтому ставка хранится в сотых долях процента.

**Срок кредита ограничен сверху.** Без границы срок из запроса задаёт
размер среза платежей напрямую — это способ исчерпать память сервиса
одним запросом.

**Расчёт проверен табличными тестами на границах**: минимальная сумма,
предельный срок, нулевой остаток. Ошибка в расчёте платежа — это ошибка
в деньгах, и ловить её на пользователях нельзя.

**Погашение идёт через кошелёк по gRPC** с ключом идемпотентности:
распределённой транзакции между сервисами нет, поэтому порядок выбран так,
чтобы повтор после сбоя не списал средства дважды.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/credits` | Оформить кредит; другому пользователю — с ролью оператора |
| `GET` | `/credits` | Свои кредиты |
| `GET` | `/credits/{id}/payments` | График платежей |
| `POST` | `/credits/{id}/payments` | Внести платёж |

Точный список — в [_requests/credit.http](../../../_requests/credit.http).

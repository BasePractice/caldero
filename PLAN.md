## Блок A. Критично: безопасность и неработающий код

Пока не закрыт этот блок, новая функциональность не разрабатывается.

| № | Задача | Почему критично |
|---|---|---|
| **T-001** | Закрыть обход аутентификации через `X-Authorized-Id` | Любой может выполнить операцию от имени любого пользователя |
| **T-002** | Устранить IDOR в кошельке | Чтение баланса и транзакций чужого кошелька |
| **T-003** | Починить сломанные SQL-запросы в `users` | Подпись JWT, ротация ключей и отзыв токенов не работают вообще |
| **T-004** | Загружать `.env` до инициализации конфигурации | Ни одна переменная окружения из файла не применяется |
| **T-005** | `return` после ответа `4xx` в обработчиках | Невалидные данные всё равно пишутся в БД |
| **T-006** | Закрыть `/rotate-keys` и `/revoke` авторизацией | Анонимная инвалидация всех токенов + CPU-DoS |
| **T-007** | `GlobalSecret` из окружения, выключить debug-сообщения клиенту | Рестарт ломает все токены; утечка внутренних ошибок |
| **T-008** | Fail-fast вместо `nil` из конструкторов | Сервис поднимается заведомо нерабочим |
| **T-009** | Убрать `panic("implement me")` из репозиториев | Нарушает `RULE.md`; паника в обработчике вместо ошибки |
| **T-010** | Переполнение `uint` и деление на ноль в расчёте платежей | OOM/паника по данным из БД |
| **T-011** | `credit.Get` не выбирает поля, от которых зависит расчёт | График платежей считается неверно |
| **T-012** | Неверный `GROUP BY` в запросе кошелька | Дубли кошельков и неправильные суммы резервов |
| **T-013** | Гонка при автосоздании кошелька | Параллельные запросы падают на `UNIQUE` |
| **T-014** | UUID форматируется через `%d` | В заголовок уходит массив байт вместо идентификатора |
| **T-015** | `DROP TABLE` в неверном порядке в down-миграции | Откат миграции невозможен |
